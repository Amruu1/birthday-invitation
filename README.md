# Birthday Invitation

Website ulang tahun digital dengan HTML5, CSS3, dan Vanilla JavaScript.

## Menjalankan
Buka `index.html` langsung di browser atau jalankan server lokal sederhana.

## Struktur
- `index.html` — markup dan konten 
- `css/style.css` — desain, layout landscape, dan responsivitas
- `js/script.js` — navigasi, passcode, galeri, hadiah, dan interaksi lilin
- `assets/img/` — foto, ilustrasi peta lokal, dan aset visual
